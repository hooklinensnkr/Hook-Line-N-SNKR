# Hook Line N SNKR - Custom Clothes E-commerce

A modern e-commerce platform for selling custom-made clothes.

## Getting Started

### Installation

```bash
git clone https://github.com/hooklinensnkr/Hook-Line-N-SNKR.git
cd Hook-Line-N-SNKR
npm install
cp .env.example .env.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see your site.

## Setup Stripe

1. Create account at https://stripe.com
2. Get API keys from dashboard
3. Add to .env.local file
